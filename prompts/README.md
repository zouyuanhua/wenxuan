# prompts —— Prompt 模板与版本管理

## 目录约定

```
prompts/
├── interpretation/     # 解读主模板
│   ├── v1.0.md         # 版本化存放,不覆盖历史版本
│   └── v1.1.md
├── fewshot/            # few-shot 卦例(与 knowledge/cases 联动)
├── safety/             # 安全过滤与免责声明模板
└── CHANGELOG.md        # 每次变更记录:版本、改动、评测结果
```

## 核心模板要点(解读主 Prompt)

1. 注入:排盘 JSON + 规则结论 + 典籍原文,**禁止引入数据之外的卦理**
2. 输出五段结构:卦象直读 → 核心矛盾 → 趋势判断(吉/凶/平/待时机,须与
   规则结论一致)→ 行动建议(3 条,非宿命论)→ 典籍引证
3. 语气:温和、有洞察力、不说教;400 字内;末尾固定免责声明

## 评测约定

- 每个新版本须通过固定评测集(≥ 50 问事场景)对比上一版本
- 一致性红线:AI 结论与规则层结论方向相反 = 直接判不合格
