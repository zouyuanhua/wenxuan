## 卦例库:产品的真正护城河

古籍问"求官、求财",当代用户问"offer 要不要接、该不该分手"。
"古卦今译"映射库决定解读代入感:

```
典籍卦例结构化 → 现代场景改写(1 例 → 5 个现代问法)
→ 双人交叉质检 → 入库 → 作为 few-shot 范例注入 Prompt
```
