## 方案核心结论(速览)

1. 定位:传统文化/国学文化娱乐产品,"心有惑,一卦问玄"
2. 术数选型:梅花易数(免费轻占)+ 六爻纳甲(付费深解)双引擎起步
3. 技术原则:**代码算排盘,LLM 只做解读**,三层管线保证准确性与质量
4. 合规:全站规避"算命"表述,固定免责声明,禁项清单硬编码进安全层
5. 路线:P0 验证(3 周)→ P1 MVP 付费闭环 → P2 小程序/塔罗/八字 → P3 生态
