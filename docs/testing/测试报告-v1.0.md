## 4. 单元/模块测试明细

### 4.1 摇卦引擎(engine/tests/test_yaogua.py,14/14 通过)

| 用例组 | 验证点 | 结果 |
|---|---|---|
| 钱象映射 | 一背=少阳/二背=少阴/三背=老阳(动)/三字=老阴(动),逐项精确断言;非法背面数(−1/4/99)拒绝 | ✅ |
| 概率分布 | 5 万爻模拟:老阳 12.5%/老阴 12.5%/少阳 37.5%/少阴 37.5%,绝对偏差 ≤1% | ✅ |
| 单枚公平 | 30 万次聚合背面频率 ≈ 0.5(偏差 ≤1%) | ✅ |
| 确定性 | 同种子两次摇卦结果完全一致(可复现保存) | ✅ |
| 64 卦表 | 表规模 =64;8×8 上下卦组合全覆盖;典型卦(同人/既济/泰/否/屯/蛊)抽查 | ✅ |
| 变卦推导 | 乾全动→坤;老阴动→阳(坤初爻动→地雷复);全静→无变卦 | ✅ |
| 数据结构 | to_dict 字段与 SRS 模型一致;爻位 1-6 自下而上 | ✅ |
