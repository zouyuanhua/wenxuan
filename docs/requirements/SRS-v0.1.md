## 1. 引言

### 1.1 目的
定义「问玄」P0 验证版的核心业务流程与功能需求,作为开发、测试与需求变更的基线依据。

### 1.2 范围
本文档覆盖**问事最小闭环**:来者问事 → 起卦 → 卦象分析 → 答复,及追问循环。
会员、分享海报、每日运势、塔罗/八字等模块不在本期范围。

### 1.3 术语
| 术语 | 定义 |
|---|---|
| 问事 | 用户就某一具体困惑发起的一次占问 |
| 会话 | 一次问事的全过程:问题 + 一卦 + 全部问答 |
| 摇卦 | 三枚虚拟铜钱摇六次逐爻成卦的起卦方式 |
| 动爻 | 老阳(○)/老阴(×)爻,代表变化点,阴变阳/阳变阴 |
| 本卦/变卦 | 摇卦所得原始卦 / 动爻变化后的卦 |
| 用神 | 六爻分析中代表所问之事的六亲(官鬼/妻财/父母/兄弟/子孙) |

### 1.4 核心流程与不变量

```
① 来者问事 → ② 起卦 → ③ 卦象分析 → ④ 答复
                    └─ 用户追问 ←─┘
                          ↓
                ③ 卦象分析 → ④ 答复(循环 n 次)
```

**不变量:一问一卦。** 追问不重新起卦,始终基于同一卦象深入。

## 2. 功能需求

### FR-01 来者问事

**描述**:用户选择问事分类,输入/确认问题文本。

**交互(三步极简)**:
1. 点宫格选分类(必选,8 类 + 兜底)
2. 点子项自动填入问题模板(可选,可自由编辑)
3. 确认问题 → 进入摇卦

**分类清单**:

| 一级分类 | 子项 | 示例问法模板 | 用神提示 |
|---|---|---|---|
| 💼 事业 | 求职面试/跳槽去留/晋升发展/创业开店/项目成败/职场去留 | "这个 offer 我能拿到吗?" | 官鬼(工作)、父母(单位) |
| ❤️ 感情 | 单恋暗恋/恋爱发展/挽回复合/相亲缘分/婚姻走向/暧昧关系 | "分手了还能复合吗?" | 男测女:妻财;女测男:官鬼 |
| 💰 财运 | 近期财运/生意盈亏/投资参考/借贷事宜/买卖交易 | "最近半年财运如何?" | 妻财 |
| 📚 学业 | 考试成败/升学录取/考证考编/留学申请/论文答辩 | "这场考试能过吗?" | 父母(文书)、官鬼(功名) |
| 🧭 决策 | 二选一/该不该做/时机选择/出行远行/搬迁换城 | "现在是行动的好时机吗?" | 世应关系 + 事体对应六亲 |
| 🤝 人际 | 合伙合作/是非小人/纠纷官司/请求求助 | "和这个人合伙靠谱吗?" | 官鬼(纠纷)、兄弟(是非) |
| 🏠 家宅 | 买房租房/搬家乔迁/装修动工/宅运安顿 | "这套房子适合我吗?" | 父母(宅) |
| 🔍 寻人寻物 | 寻物/寻宠物/失联联系 | "丢的东西能找回来吗?" | 按所失之人和物定六亲 |
| ✍️ 其他 | 自由输入(兜底) | — | LLM 兜底分类后定用神 |

**约束**:
- 问题文本 5–200 字;分类必选,未选子项时自由输入亦可
- 分类选定即锁定,追问阶段不可更换
- 投资参考类子项强制关联免责声明

**合规排除**(分类中不得出现):
- 健康疾病、生死预测
- 赌博彩票、具体投资标的涨跌指令
- 第三方隐私打探类问题(安全层过滤)

**验收标准**:
- [ ] 问题文本与分类被持久化,并与后续卦象绑定为一条会话记录
- [ ] 点子项可填入模板且可编辑
- [ ] 空问题/超字数输入时提示且不起卦

### FR-02 起卦(摇卦)

**描述**:用户通过摇卦交互获得本卦、动爻与变卦。

**交互**:用户点击摇卦按钮(或摇一摇手机)→ 三枚铜钱落下动画 + 声效 → 得本爻 → 重复 6 次(初爻至上爻)→ 逐爻升起成卦。全过程约 15 秒。

**规则**:
- 每次摇掷 = 3 枚独立公平硬币,每枚正反各 50%
- 四种结果(背=反面,字=正面):

| 组合 | 名称 | 得爻 | 动否 | 概率 |
|---|---|---|---|---|
| 一背二字 | 单 | 少阳 ▅▅▅▅▅ | 否 | 37.5% |
| 二背一字 | 拆 | 少阴 ▅▅ ▅▅ | 否 | 37.5% |
| 三背 | 重 | 老阳 ▅▅▅▅▅ ○ | 是(阳→阴) | 12.5% |
| 三字 | 交 | 老阴 ▅▅ ▅▅ × | 是(阴→阳) | 12.5% |

- 老阳/老阴为动爻;动爻变化推出变卦
- 中途不可中断,摇满 6 爻方可进入分析

**验收标准**:
- [ ] 单枚硬币随机公平(正反各 50%,种子不可预测)
- [ ] 每爻分布与上表一致:老阳 12.5%、老阴 12.5%、少阳 37.5%、少阴 37.5%
- [ ] 本卦 + 动爻 + 变卦计算正确(以《增删卜易》卦例抽测)
- [ ] 摇卦全过程结果可完整复现保存(逐爻记录)

### FR-03 卦象分析

**描述**:基于问题与卦象生成分析。

**处理**:排盘计算(纳甲/六亲/世应/旺衰,纯代码)→ 典籍 RAG → LLM 解读管线(三层:规则结论层/知识检索层/LLM 叙述层)。

**验收标准**:
- [ ] 排盘结果由确定性代码产出,LLM 不参与任何术数计算
- [ ] 趋势结论与规则层结论方向一致,相反即拦截重试
- [ ] 解读仅引用给定典籍原文,无编造卦理

### FR-04 答复

**描述**:向用户呈现结构化解读。

**输出结构(五段,400 字内)**:
1. 卦象直读 2. 核心矛盾 3. 趋势判断(吉/凶/平/待时机)4. 行动建议 ×3 5. 典籍引证

**验收标准**:
- [ ] 五段结构完整,缺失即重试
- [ ] 末尾固定附免责声明:"内容基于传统文化典籍生成,仅供文化娱乐参考,不构成医疗、法律、投资、婚姻等专业建议。"
- [ ] 无绝对化断言(必然/一定/百分之百)

### FR-05 追问循环

**描述**:用户可对答复继续追问,重复 ③分析 → ④答复。

**约束**:
- 追问不重新起卦,基于同一卦象与原问题上下文
- 追问须围绕本卦与本问题(超范围问题温和引导回主题)
- **次数上限:3 次**,超限后收尾:"此卦已尽,建议心定后另择时再问"

**验收标准**:
- [ ] 追问答复与原卦象自洽
- [ ] 超限后正确收尾并保存会话

## 3. 非功能需求

| 编号 | 需求 | 验收 |
|---|---|---|
| NFR-01 | 会话记录持久化 | 问题/卦象/全部问答完整落库,可回看 |
| NFR-02 | 解读响应 | 摇卦结束后解读首屏 ≤ 15 秒(流式可更早) |
| NFR-03 | 免登录 | 无需注册登录即可完成问事;记录存于本地 |
| NFR-04 | 输出安全 | 免责声明 100% 附带;敏感场景(疾病/投资指令)输出被过滤 |
