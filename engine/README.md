# engine —— 卦象引擎(技术核心一)

**设计原则:LLM 只当"解卦人",不当"算卦人"。** 所有术数计算由确定性代码完成,
LLM 仅基于计算结果与典籍知识库做叙事。

## 模块规划

| 模块 | 实现方案 | 要点 |
|---|---|---|
| 农历/干支转换 | lunar-python / sxtwl | 精确到时辰;注意 23:00-01:00 子时换日规则 |
| 梅花起卦 | 年月日时卦、报数卦、方位卦 | 纯算法,确定性,用于免费轻占 |
| 六爻摇卦 | 三枚铜钱模拟 | 每爻概率与手工一致(老阳 12.5%/老阴 12.5%/少阳 37.5%/少阴 37.5%) |
| 纳甲装卦 | 64 卦宫位表 + 纳甲规则查表 | 逻辑写死代码,离线可跑,逐卦单测 |
| 旺衰判定 | 月建/日辰对爻生克的规则引擎 | 规则引擎,可单测验证 |

## 统一数据模型

每次问事产出一个结构化卦象 JSON(本卦/互卦/变卦、六爻阴阳动静、地支六亲、
世应、用神旺衰与关键生克),是解读、存储、复盘、训练数据的原子单位。
字段定义见 `schema.md`(待建)。

## 验收标准

1. 以《增删卜易》《卜筮正宗》100 个实战卦例回测,排盘结果与原例 **100% 一致**
2. 核心模块(干支、纳甲、旺衰)单元测试覆盖率 **> 90%**
3. 同一输入任意时间重放,结果完全一致(确定性)
